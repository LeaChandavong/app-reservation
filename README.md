# app-reservation

Projet conçu en équipe avec : Naomi, Lea, Federer

## Le problème

- Problème : Pas d'image de référence du matériel, 
- Persona : Mike veut réserver un matériel spécifique mais il ne sait pas le nom du matériel, il sait seulement à quoi il ressemble.

## La solution

- Proposition de valeur : Ça serait plus efficace et facile de naviguer en ayant des images pour une aide plus visuel.
- Fonctionnalités du MVP :
    - En tant que étudiant, je veux rajouter des images afin de faciliter une utilisation en réservation.
